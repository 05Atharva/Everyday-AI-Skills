# Surgical Bullet Rewriting Examples

These examples demonstrate how to reframe existing bullets using JD language — without inventing new content.

---

## Principle: Reframe, Don't Fabricate

The original content must contain the core claim. The edit only surfaces it with better vocabulary or structure.

---

## Software Engineering

**JD signals:** "Designed scalable backend systems", "RESTful API development", "collaborated cross-functionally"

Before: `Built APIs for the product using Flask`
After: `Designed and developed RESTful APIs using Flask to support product backend functionality`

Before: `Worked with the frontend team`
After: `Collaborated cross-functionally with frontend engineers to align API contracts and delivery timelines`

---

## Data Science

**JD signals:** "Built predictive models", "drove business insights", "stakeholder reporting"

Before: `Made a churn prediction model in Python`
After: `Developed a customer churn prediction model using Python, delivering actionable insights for retention strategy`

Before: `Created reports for the team`
After: `Produced stakeholder-facing analytical reports translating model outputs into business recommendations`

---

## Product Management

**JD signals:** "Led product roadmap", "data-driven prioritization", "cross-functional execution"

Before: `Helped plan the roadmap for Q3`
After: `Contributed to Q3 product roadmap planning, supporting data-driven prioritization across engineering and design teams`

(Note: "Helped" → "Contributed to" is acceptable. "Led" would require KB evidence of actual ownership.)

---

## Cybersecurity

**JD signals:** "Performed vulnerability assessments", "incident response", "MITRE ATT&CK"

Before: `Found security issues in the web app`
After: `Conducted vulnerability assessments on web application layers, identifying and documenting critical security gaps`

---

## Marketing

**JD signals:** "Performance marketing", "growth campaigns", "conversion optimization"

Before: `Ran ads on Facebook and Google`
After: `Managed performance marketing campaigns across Meta and Google Ads, focused on conversion optimization and CAC reduction`

---

## Anti-Pattern Examples (Do NOT do these)

❌ `Increased system performance by 40%` — if no metric was in KB
✅ `Improved system performance through query optimization` — if optimization is in KB

❌ `Led a team of 5 engineers` — if user only mentioned "worked with engineers"
✅ `Collaborated with a team of engineers` — accurate to KB

❌ `Used LangChain and LlamaIndex for RAG pipeline` — if only "chatbot" was mentioned
✅ `Built a conversational AI assistant` — stick to what's stated

---

## Verb Upgrade Guide (use only if KB supports the action)

| Weak Verb | Stronger Alternative | Condition |
|---|---|---|
| worked on | developed, contributed to | if involvement is confirmed |
| helped | supported, assisted | if not leading |
| made | built, designed, implemented | if creation is confirmed |
| looked at | analyzed, reviewed, evaluated | if analysis is confirmed |
| ran | executed, managed, led | only if ownership is confirmed |
| used | leveraged, applied, utilized | always safe |
