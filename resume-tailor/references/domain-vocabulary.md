# Domain Vocabulary Reference

Use this to accurately map JD language to the correct domain and adjust tailoring tone/vocabulary accordingly.

---

## Domain Detection Signals

### Software Engineering
Signals: "backend", "frontend", "full-stack", "API", "microservices", "distributed systems", "DevOps", "deployment"
Tone: Technical, precise, architecture-focused
Emphasis: System design, scalability, code quality, delivery

### AI / Machine Learning
Signals: "LLM", "model", "training", "inference", "NLP", "computer vision", "MLOps", "embeddings", "fine-tuning"
Tone: Research-aware + engineering-rigorous
Emphasis: Model performance, experimentation, production deployment

### Data Science / Analytics
Signals: "insights", "dashboards", "SQL", "A/B testing", "data pipeline", "statistical modeling", "business intelligence"
Tone: Business-outcome oriented
Emphasis: Measurable impact, business insights, stakeholder communication

### Cybersecurity
Signals: "threat", "vulnerability", "incident", "SOC", "penetration", "compliance", "zero trust"
Tone: Risk-aware, methodical
Emphasis: Frameworks, certifications, detection/response capabilities

### Mobile Development
Signals: "iOS", "Android", "app", "Swift", "Kotlin", "React Native", "Flutter", "App Store"
Tone: User-experience aware + technically specific
Emphasis: Platform-specific expertise, performance, UX quality

### Embedded / IoT
Signals: "firmware", "RTOS", "microcontroller", "sensor", "protocol", "hardware", "real-time"
Tone: Highly technical, low-level
Emphasis: Hardware-software interface, reliability, protocol expertise

### Product Management
Signals: "roadmap", "stakeholder", "OKR", "go-to-market", "prioritization", "user research", "sprint"
Tone: Strategic + execution-oriented
Emphasis: Impact on metrics, cross-functional leadership, customer empathy

### UI/UX Design
Signals: "wireframe", "prototype", "usability", "accessibility", "design system", "user research", "Figma"
Tone: Human-centered, process-aware
Emphasis: Process rigor, user empathy, design system thinking

### Finance
Signals: "valuation", "financial model", "DCF", "portfolio", "M&A", "investment", "P&L", "forecasting"
Tone: Precise, quantitative
Emphasis: Accuracy, analytical rigor, domain certifications (CFA, CPA)

### Marketing
Signals: "campaign", "growth", "conversion", "SEO", "brand", "content", "performance marketing", "ROI"
Tone: Results-driven, audience-aware
Emphasis: Measurable outcomes (ROAS, CTR, CAC), channel expertise

### Consulting
Signals: "client", "engagement", "deliverable", "workstream", "framework", "due diligence", "stakeholder"
Tone: Structured, executive-ready
Emphasis: Problem-solving methodology, communication, client impact

## Cross-Domain Vocabulary Equivalents

Some concepts exist across domains but with different vocabulary. Match to the JD's phrasing:

| Generic | Software | Data | Product | Consulting |
|---|---|---|---|---|
| "Built X" | Engineered / Architected | Developed / Modeled | Shipped / Launched | Delivered / Designed |
| "Worked with team" | Collaborated cross-functionally | Partnered with stakeholders | Aligned across functions | Managed workstreams |
| "Improved performance" | Optimized latency/throughput | Improved model accuracy | Increased key metric by X% | Drove operational efficiency |
| "Led initiative" | Owned technical design | Spearheaded analysis | Drove product direction | Led engagement workstream |
